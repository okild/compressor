# compressor
A program for compressing text into cipher and then compiling it back into text.


Архитектура системы адаптивной бинарной сериализации и энтропийного сжатия данных
1. Техническая спецификация (Abstract)
Данный программный комплекс представляет собой высокоуровневую реализацию конвейера обработки данных, предназначенного для детерминированной редукции информационной избыточности строковых примитивов. В основе решения лежит гибридный метод, сочетающий словарное сжатие в скользящем окне и последующую трансформацию бинарного домена в ASCII-совместимый транспортный формат.
2. Операционный алгоритм и внутренняя механика
Фаза А: Дифференциальная дефляция (Entropy Reduction)
Процесс инициализируется через абстракцию библиотеки zlib, задействующей алгоритм DEFLATE.
Лексический анализ: Реализуется поиск повторяющихся паттернов на базе метода LZ77, где дублирующиеся последовательности замещаются обратными ссылками на лексический словарь в рамках префиксного дерева.
Битовая упаковка: Финальная стадия сжатия оперирует динамическим кодированием Хаффмана, перераспределяя битовую плотность в пользу символов с максимальной частотой возникновения. Уровень сжатия установлен на level=9, что обеспечивает предельную глубину рекурсивного поиска соответствий для минимизации выходного объема.
Фаза Б: Трансфигурация в Base64-континуум
Для обеспечения инвариантности данных при передаче по протоколам, чувствительным к непечатным символам, применяется Base64-кодирование с модификацией urlsafe.
Алгоритм осуществляет перегруппировку 8-битных байтов в 6-битные сегменты, которые затем мапятся на защищенный алфавит [A-Z, a-z, 0-9, -, _].
Использование URL-safe вариации исключает необходимость в эскейпировании специальных символов (таких как + или /), что критически важно для интеграции в URL-параметры или NoSQL-структуры.
3. Инструкция по эксплуатации (Deployment Guide)
Для инициализации цикла трансформации пользователю предоставляется консольный интерфейс (CLI) с циклом опроса событий.
Процедура сжатия (Encryption/Compression)
Активируйте скрипт в среде интерпретатора Python 3.x.
Выберите опцию 1 для инициализации вектора записи.
Введите строковую последовательность. Система произведет UTF-8 кодирование, дефляцию и вернет результирующий токен.
Процедура восстановления (Decompression/Restoration)
Выберите опцию 2.
Передайте ранее сгенерированный Base64-токен.
Блок обработки исключений (try-except) выполнит валидацию целостности структуры, проверит контрольную сумму zlib и осуществит реверсивное преобразование в исходный текст.
Примечание по отказоустойчивости: Система оснащена механизмами перехвата ошибок zlib.error и UnicodeDecodeError, что предотвращает фатальное завершение процесса при попытке обработки поврежденных или некорректно сформированных входных данных.
